# DESIGN SYSTEM

The visual style should be:
- minimal
- professional
- modern
- calm
- clean
- developer-oriented
- information-focused

## Color Palette
- **Background:** `#F7F7F5`
- **Surface:** `#FFFFFF`
- **Primary Text:** `#18181B`
- **Secondary Text:** `#71717A`
- **Border:** `#E4E4E7`
- **Accent:** `#6D5CE7`

## Typography
- **Fonts:** `Inter, ui-sans-serif, system-ui, sans-serif`

## Avoid (Strict constraints)
- neon UI
- excessive gradients
- glassmorphism
- glowing borders
- huge typography
- excessive rounded cards
- heavy shadows
- unnecessary charts
- excessive animations
- futuristic AI effects

The goal is a credible product prototype for a DevJams Review 1 presentation.
