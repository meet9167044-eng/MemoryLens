# WORKFLOW & PHASES

The project is intentionally divided into phases.

## High-Level Progression
- **Phase 1:** Frontend Foundation
- **Phase 2:** Synthetic Data
- **Phase 3:** Overview + Application Shell
- **Phase 4:** Memory Explorer
- **Phase 5:** Memory Detail
- **Phase 6:** Search + Timeline
- **Phase 7:** Connections + Insights
- **Phase 8:** Final Review 1 Polish

## Important Development Rule for Agents
When instructed to "Do Phase [X]":
1. **ONLY execute Phase [X].** Do not jump ahead.
2. Read the corresponding file inside `Phases/` before doing the work.
3. After completing a phase:
   - Test it
   - Verify existing functionality
   - Update `docs/STATUS.md`
   - Report what was completed
   - Report any issues
   - **STOP**. Do not automatically continue to the next phase.
