# Collaboration Rules

- When you are told: "Do Phase [X]", you must **ONLY** execute Phase [X].
- Do not jump ahead when a phase is requested.
- Read the corresponding file inside `Phases/` before doing the work.
- After completing a phase:
  1. Test it
  2. Verify existing functionality
  3. Update `docs/STATUS.md`
  4. Report what was completed
  5. Report any issues
  6. **STOP**
- Do not automatically continue to the next phase.
