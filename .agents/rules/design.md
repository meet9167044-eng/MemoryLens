# Design Rules

- Use `docs/DESIGN_SYSTEM.md` as the visual source of truth.
- The visual style must be: minimal, professional, modern, calm, clean, developer-oriented, information-focused.
- Avoid neon UI, excessive gradients, glassmorphism, glowing borders, huge typography, excessive rounded cards, heavy shadows, unnecessary charts, excessive animations, futuristic AI effects.
- The application should feel like a professional developer productivity tool. It should NOT look like a flashy AI demo.
